✨ Admin Login Passcode ("Magic Word")
A temporary, quick alternative to email/password sign-in on this admin panel. Real email/password login stays fully available alongside it.
⚠️ Changing this passcode will immediately sign out the current session and require the new passcode (or your email/password) to sign back in.
Stored as a hash — never saved or visible in plain text.
🔒 Public Access Gate
Require a password before anyone can view the public portal (index page)
⚠️ Note: since the public portal is a static page with no backend server, this is a deterrent gate, not real security — it stops casual browsing, search engine indexing, and accidental link-sharing, but a determined technical visitor could bypass it. Don't rely on this to protect sensitive data; the underlying Firestore data is only as protected as your database security rules.
Leave blank if you're only toggling the switch above without changing the password. The password is hashed before saving — nobody, including Anthropic or Google/Firebase, can see the plain text.
